使用以下方式之一上传:

1. 自动上传脚本:
   双击 upload_to_github.bat
   或在 PowerShell 中运行: .\upload_to_github.bat

2. GitHub Desktop:
   打开 GitHub Desktop → Add Local Repository

3. 命令行:
   git init
   git add .
   git commit -m "Initial commit: 智慧养老监护平台"
   git remote add origin https://github.com/jj-s2/look-model.git
   git branch -M main
   git push -u origin main

4. VS Code:
   左侧 Source Control → Initialize → Stage All → Commit → Push

5. 网页上传:
   访问 https://github.com/jj-s2/look-model/upload/web
