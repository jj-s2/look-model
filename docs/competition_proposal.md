# 基于多模态 AI 监测的老年人跌倒风险前置防控系统

## 海康威视揭榜挂帅参赛方案

> 题目：基于多模态 AI 监测的老年人跌倒风险、心理健康、诈骗识别及预警研究
> 方向：跌倒风险（单方向做深）
> 发榜单位：杭州海康威视数字技术股份有限公司
> 平台要求：萤石开放平台

---

## 一、方案概述

### 1.1 问题定位

赛题明确指出："现有技术在跌倒行为识别方面已具备较高精度，但整体仍以事后检测与响应为主，在跌倒发生前的风险预判与前置防控方面能力不足"。

本方案聚焦**跌倒风险前置防控**，针对"事后响应"模式的根本缺陷，构建"**跌倒前预判 → 跌倒时预警 → 跌倒后快速响应**"的全流程技术体系，在现有跌倒动作识别（事后）能力之上，新增**跌倒前风险预判**这一核心创新模块，并通过多模态数据融合提升预判准确性与场景适配性。

### 1.2 核心创新点

1. **从二分类到连续风险评分**：突破传统"跌倒/非跌倒"二分类范式，输出连续的跌倒风险概率曲线，支持分级预警
2. **前置预判能力**：基于骨架时序的步态稳定性分析，在跌倒发生前识别风险征兆（步态抖动、重心异常摆动、起身困难、长时间静止等）
3. **多模态融合**：视频骨架 + 环境上下文（时段、场景、光照）加权风险评分
4. **分级预警闭环**：低/中/高三級风险驱动差异化响应（提示/告警/紧急联动）

### 1.3 与现有技术对比

| 维度 | 传统方案 | 萤石现有能力 | 本方案 |
|------|---------|------------|--------|
| 识别时机 | 跌倒后 | 跌倒后（准确率 80%+） | 跌倒前+跌倒时+跌倒后 |
| 输出形式 | 二分类 | 二分类 | 连续风险评分 + 分级预警 |
| 模态 | 单一视频 | 单一视频 | 视频+环境+行为时序 |
| 响应 | 事后告警 | 事后告警 | 前置预判+分级响应闭环 |

7. 融合：final_risk = Σ wi·scorei
8. 分级预警：按阈值触发响应

## 三、核心技术创新

### 3.1 跌倒前预判：步态稳定性评分

**问题**：传统方法只能识别"已经跌倒"，无法预判"即将跌倒"。

**方法**：从骨架时序中提取步态稳定性指标，构建连续风险评分：

| 指标 | 计算方式 | 异常含义 |
|------|---------|---------|
| 步频抖动度 | 连续帧脚步关键点(15,16)的速度方差 | 步频紊乱、平衡失调 |
| 重心摆动幅度 | 髋部中点(8,11)横向位移标准差 | 重心不稳 |
| 身体倾斜角变化 | 肩-髋连线与垂直方向夹角的时序变化 | 身体前倾/后仰失控 |
| 起身困难度 | 从坐/躺到站的持续时间与关键点速度峰值 | 腿部力量不足 |
| 静止异常 | 长时间(>10s)非卧姿静止 | 可能头晕或不适 |
| 活动骤降 | 短时间内活动量突降 | 可能身体不适 |

**评分模型**：

```
risk_score = sigmoid(Σ αi · normalize(indicator_i))
```

- 各指标归一化后加权求和
- 权重 αi 通过 GMDCSA24 数据集的 Fall 前片段学习（Fall 样本前 10-30 秒的骨架序列作为"高风险"正样本）
- 输出 [0, 1] 连续风险概率

**数据基础**：GMDCSA24 数据集包含 Fall 事件完整视频，可截取 Fall 发生前片段作为前置风险预判的训练数据。

### 3.2 多模态融合

**环境上下文加权**：

| 上下文因子 | 权重影响 | 依据 |
|-----------|---------|------|
| 夜间 (22:00-06:00) | ×1.3 | 夜间跌倒风险高、光照差 |
| 卫生间场景 | ×1.4 | 湿滑、空间狭小 |
| 楼梯/台阶附近 | ×1.5 | 跌倒高发位置 |
| 独居 | ×1.2 | 无人及时救助 |
| 近期有跌倒记录 | ×1.3 | 复发风险高 |

**融合公式**：

```
final_risk = clamp(
    (w1·fall_prob + w2·risk_score) · ctx_weight,
    0, 1
)
```

- w1=0.4（事后识别权重）
- w2=0.6（前置预判权重，体现创新）
- ctx_weight 由环境因子乘积决定

### 3.3 分级预警机制

| 等级 | 阈值 | 响应动作 | 延迟要求 |
|------|------|---------|---------|
| 低风险 | <0.3 | 静默记录到日志，APP 可查 | - |
| 中风险 | 0.3-0.6 | APP 推送提示"注意安全" | <30s |
| 高风险 | 0.6-0.8 | APP 告警 + 紧急联系人通知 | <10s |
| 紧急 | ≥0.8 | 现场语音提醒 + 电话告警 + 萤石云联动 | <3s |

**防误报机制**：高风险需连续 N 帧（如 3 帧/3 秒）超阈值才触发，避免单帧抖动误报。

### 4.3 推理流程

```python
# 伪代码：实时推理主循环
for frame in ezviz_stream:
    persons = detector(frame)
    if not persons:
        context_engine.update_no_person()
        continue

    keypoints = pose_extractor(frame, persons)
    skeleton_seq.append(keypoints)  # 滑动窗口

    # 跌倒时预警（事后识别，48帧窗口）
    if len(skeleton_seq) >= 48:
        fall_prob = fall_detector(skeleton_seq[-48:])

    # 跌倒前预判（前置风险，100帧窗口）
    if len(skeleton_seq) >= 100:
        risk_score = gait_stability(skeleton_seq[-100:])

    # 多模态融合
    ctx_weight = context_engine.get_weight()
    final_risk = fusion(fall_prob, risk_score, ctx_weight)

    # 分级预警
    alert_engine.update(final_risk)
```

## 六、评测方案

### 6.1 评测指标体系

| 指标 | 定义 | 目标 |
|------|------|------|
| 跌倒识别准确率 | (TP+TN)/(TP+FP+FN+TN) | ≥90% |
| 跌倒召回率 | TP/(TP+FN) | ≥95%（漏检优先） |
| 跌倒 F1 | 2·P·R/(P+R) | ≥0.90 |
| 前置预判提前量 | 风险评分超阈值距跌倒发生的时间 | ≥5s |
| 前置预判召回率 | 正确预判的 Fall 事件数/总 Fall 事件数 | ≥80% |
| 响应延迟 | 从事件发生到告警推送 | <3s（紧急） |
| 误报率 | FP/(FP+TN) | <5% |

### 6.2 验证数据

| 数据集 | 用途 | 状态 |
|--------|------|------|
| GMDCSA24 | 跌倒识别 LOSOCV | ✅ 已有，F1=0.91 |
| GMDCSA24 Fall 前片段 | 前置预判训练与验证 | 🆕 需截取 |
| 萤石摄像头实测 | 真实场景验证 | 🆕 需申请设备 |
| 自建场景测试集 | 客厅/卧室/卫生间多场景 | 🆕 需录制 |

### 6.3 验证方案

1. **离线验证**：GMDCSA24 LOSOCV 评估跌倒识别 + Fall 前片段评估前置预判
2. **在线验证**：萤石摄像头实时拉流，模拟跌倒场景测试响应延迟
3. **多场景验证**：客厅/卧室/卫生间/楼梯不同场景准确率对比
4. **长期验证**：连续运行 24-48 小时，统计误报率

## 七、适老化设计

### 7.1 交互适老化

- **无感监测**：老人无需操作任何设备，摄像头自动监测
- **语音优先**：高风险时语音提醒（"您可能要跌倒了，请坐下休息"），而非文字推送
- **简化告警**：紧急联系人收到简化告警（"老人可能跌倒，请查看"），附萤石云录像链接
- **方言支持**：语音提醒支持方言（可选，后期）

### 7.2 设备适老化

- **非接触式**：摄像头安装，老人不需佩戴任何设备
- **隐私保护**：卫生间等敏感场景可仅用骨架推理（不传输视频画面）
- **低光照适配**：夜间红外模式下的关键点提取适配

### 7.3 服务适老化

- **分级响应**：非紧急不打扰老人正常生活
- **家属联动**：中高风险自动通知紧急联系人
- **健康档案**：长期记录步态稳定性变化趋势，供医生参考

| 误报率高影响体验 | 评分扣分 | 分级预警+防误报机制+N帧确认 |
| 计算资源不足 | 实时性差 | 模型轻量化+抽帧降速+边缘部署 |

### A.2 跌倒前预判验证结果（步态稳定性评分）—— 核心创新点

**验证设置**：
- 数据：GMDCSA24，63 个 Fall 视频的跌倒前 5 秒片段 vs 81 个 ADL 片段
- 模型：GaitStabilityAnalyzer，4 项末段变化率指标加权融合
- 评测：ROC-AUC、不同阈值下的 TPR/FPR/F1

**核心指标区分度**（Fall 前 5s vs ADL）：

| 指标 | Fall 前均值 | ADL 均值 | 区分度 |
|------|------------|---------|--------|
| activity_burst（活动突增比） | 2.34 | 0.84 | **0.75** |
| lean_trend（倾斜增大趋势） | 4.50 | -5.42 | **0.67** |
| com_sway（重心横向摆动） | 30.87 | 71.72 | 0.57 |
| com_vel_y（末段重心下降速度） | 0.61 | 0.04 | 0.22 |

**风险评分性能**：

| 指标 | 值 |
|------|----|
| ROC-AUC | **0.8456** |
| 阈值 0.3 时 TPR（跌倒前检出率） | **90.5%** |
| 阈值 0.3 时 FPR（ADL 误报率） | 33.3% |
| 阈值 0.3 时 F1 | **0.7755** |
| 跌倒前 3 秒预判检出率（阈值 0.5） | 46.0% |
| 跌倒前 3 秒预判检出率（阈值 0.3） | ~90% |

**关键结论**：
1. 前置预判算法有效，ROC-AUC=0.85，能在跌倒前 3 秒以 90% 召回率预判风险
2. 最强指标是"活动突增比"（区分度 0.75）——跌倒前人从静坐突变为异常动作
3. 第二强是"倾斜增大趋势"（区分度 0.67）——身体开始失去平衡
4. GMDCSA24 Fall 多为"坐着→跌倒"，因此"末段变化率"比"整窗绝对值"更有效
5. 规则版权重已按区分度校准，后续可用逻辑回归进一步提升
