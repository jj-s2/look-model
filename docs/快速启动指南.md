# 快速启动指南

## Windows系统启动步骤

### 1. 安装PostgreSQL

下载并安装PostgreSQL 15: https://www.postgresql.org/download/windows/

安装后创建数据库：
```cmd
psql -U postgres
CREATE DATABASE elderly_monitor;
\q
```

### 2. 启动后端

```cmd
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
notepad .env
```

编辑`.env`文件，修改数据库连接和萤石密钥（如果有）。

启动后端：
```cmd
python -m app.main
```

或者：
```cmd
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### 3. 启动前端

新开一个命令行窗口：
```cmd
cd frontend
npm install
npm run dev
```

### 4. 启动模拟设备（可选）

新开一个命令行窗口：
```cmd
cd mock
pip install httpx
python mock_device_server.py
```

### 5. 访问系统

- 前端: http://localhost:3000
- 后端API文档: http://localhost:8000/docs
- 后端健康检查: http://localhost:8000/health

## 常见问题

### Q1: 后端启动失败，提示数据库连接错误

确保PostgreSQL服务正在运行，并且`.env`中的数据库连接信息正确。

### Q2: 前端无法连接后端

检查后端是否正常启动在8000端口，查看浏览器控制台是否有CORS错误。

### Q3: WebSocket连接失败

确保后端启动正常，前端WebSocket连接地址正确（开发环境会自动代理到后端）。

### Q4: 模拟设备发送失败

确保后端已经启动，并且数据库中有设备记录。可以先通过API文档手动创建设备。

## 手动创建测试数据

访问 http://localhost:8000/docs，使用以下接口创建测试数据：

### 1. 创建摄像机设备

```json
POST /api/v1/devices
{
  "device_serial": "C12345678",
  "device_type": "camera",
  "device_name": "卧室摄像机",
  "location": "卧室"
}
```

### 2. 创建雷达设备

```json
POST /api/v1/devices
{
  "device_serial": "R12345678",
  "device_type": "radar",
  "device_name": "床边雷达",
  "location": "卧室"
}
```

### 3. 上报风险事件（模拟AI结果）

```json
POST /api/v1/ai/events
{
  "device_id": "camera_C12345678",
  "person_id": "person_01",
  "timestamp": "2026-07-25T10:30:00Z",
  "event_type": "fall_risk",
  "risk_score": 0.85,
  "risk_level": "HIGH",
  "status": "walking_unstable",
  "reasons": ["身体左右摆动增加", "行走速度下降"]
}
```

现在可以在前端看到数据了！
