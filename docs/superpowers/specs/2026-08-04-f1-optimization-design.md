# PA-DTSF 综合 F1 优化设计

## 1. 目标与默认决策

本轮以“提高跌倒二分类综合 F1”为主目标，同时设置 Recall 下限，避免为了减少误报而增加漏检。用户要求一次性生成方案，因此本文直接采用以下默认决策：

- 主选择指标：受试者隔离验证的 binary F1。
- 安全约束：Recall 不低于当前 test 基线 0.750，目标不低于 0.800。
- 不使用 test split 选择超参数、阈值、温度或训练轮数。
- 继续使用 RTX 4060 Laptop GPU、PyTorch 2.4.1+cu121 和现有 GMDCSA24 骨架缓存。
- 当前 release 仍采用长时 64 帧骨架分支，`short_quality=0`。
- 心理健康模块不纳入本次监督学习优化，因为当前 release 没有经过审核的心理健康标签。

## 2. 当前证据基线

| 划分 | 样本 | 阳性 | Precision | Recall | F1 | ROC-AUC | AP | Brier |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| train | 91 | 44 | 0.881 | 0.841 | 0.860 | 0.935 | 0.933 | 0.107 |
| validation | 37 | 15 | 0.579 | 0.733 | 0.647 | 0.794 | 0.763 | 0.300 |
| test | 32 | 16 | 0.800 | 0.750 | 0.774 | 0.836 | 0.890 | 0.215 |

训练与验证 F1 相差 0.213，且 validation Brier 达 0.300，说明主要问题不是类别不平衡，而是固定顺序单样本训练、缺少验证早停、模型过度自信和跨受试者泛化不足。

## 3. 候选路线

### 路线 A：只做阈值与温度校准

优点是改动小、训练快、能改善概率可信度。缺点是不能改变样本排序，因此不会提高 ROC-AUC；若在 test 上选择阈值还会造成泄漏。它只适合作为最终步骤，不能作为核心算法创新。

### 路线 B：受试者感知的正则化训练（推荐）

把现有单样本固定顺序循环替换成真正的批训练、随机打乱、骨架时序增强、验证早停和验证集校准。超参数仅由 subject-2/3/4 的内层分组验证选择，subject-1 只作最终确认。该路线直接针对当前过拟合根因，改动可控，也便于做消融实验。

### 路线 C：更大网络与多数据集预训练

引入 ST-GCN/CTR-GCN、PoseC3D 或多个公共跌倒数据集，理论上限最高，但数据适配、域差异和训练成本明显更大。在只有 4 个 GMDCSA24 受试者时直接增加模型容量很可能进一步过拟合。因此把它作为第二阶段扩展，不作为本轮首选。

## 4. 推荐架构

### 4.1 数据协议

冻结现有 subject-1 test split，不用它做任何选择。对 subject-2、subject-3、subject-4 做三折内层验证：每折用两个受试者训练、一个受试者验证。候选配置按三折 mean F1 排序，若 Recall 低于 0.750 则淘汰；并用 worst-subject F1 作为并列时的优先项。

确定配置后，用 subject-2/3/4 合并训练最终模型。训练轮数取内层三折最佳 epoch 的中位数，不再查看 subject-1。最后对 subject-1 运行一次固定阈值评估。由于旧 release 已经看过 subject-1 结果，报告必须把它称为“固定确认集”，不能再声称完全未见。

### 4.2 训练数据管线

新增独立 `PhasePoseDataset`，一次返回一条 `(64,17,3)` pose、fall label、subject id 和 provenance。DataLoader 使用 `batch_size=8`、`shuffle=True`，不再按清单固定顺序逐条训练。

仅对训练批次执行以下标签保持增强：

- COCO-17 左右关节映射后的水平翻转，概率 0.5。
- 时间轴轻微伸缩后重采样回 64 帧，比例 0.90–1.10。
- 坐标高斯噪声，标准差 0.01（在人体尺度归一化后）。
- 随机关键点遮挡，概率 0.05，同时把 confidence 置零。
- 连续帧遮挡 2–6 帧，概率 0.20，用于模拟码流丢帧和遮挡。

validation/test 禁止任何随机增强。

### 4.3 模型与损失

保留 PA-DTSF 长时 TCN 主体，避免在小数据上扩大容量。候选搜索只包含：

- `hidden_dim ∈ {64, 96, 128}`。
- `dropout ∈ {0.25, 0.35, 0.45}`。
- `learning_rate ∈ {1e-4, 3e-4}`。
- fall loss 使用 `BCEWithLogitsLoss`，正标签平滑到 0.95、负标签平滑到 0.05。

采用 AdamW、`weight_decay=1e-3`、梯度裁剪 1.0、CosineAnnealing 学习率和最多 60 epoch。以 validation F1 为主、AP 为并列指标，patience=8 早停。每个候选只运行 seed 42；最终选定配置再运行 seed 42/43/44，比较单模型与三模型概率平均。只有 ensemble 的内层 mean F1 至少提高 0.02 才保留 ensemble，否则发布单模型。

### 4.4 校准与阈值

每个内层折只使用该折 validation logits 拟合一个标量 temperature，目标为最小化 NLL。最终 temperature 取三折中位数。阈值在内层 validation 汇总预测上从 0.20–0.80、步长 0.01 搜索，最大化 subject-macro F1，并强制 Recall ≥ 0.750。固定 temperature 和 threshold 后才允许评估 subject-1。

线上预测仍保留质量门控；低质量窗口不会因为校准而升级为确认跌倒。

## 5. 实验矩阵与消融

按以下顺序运行，后一个实验只在前一个通过验证门槛后继续：

| ID | 批训练/打乱 | 增强 | 正则化/早停 | 校准 | 目的 |
| --- | --- | --- | --- | --- | --- |
| E0 | 否 | 否 | 否 | 否 | 复现当前基线 |
| E1 | 是 | 否 | 是 | 否 | 验证训练协议修复 |
| E2 | 是 | 是 | 是 | 否 | 验证骨架增强贡献 |
| E3 | 是 | 是 | 是 | 是 | 验证校准与固定阈值贡献 |
| E4 | E3 | E3 | E3 | E3 | 三 seed ensemble，仅在增益 ≥0.02 时保留 |

每个实验输出三折 F1/Precision/Recall/ROC-AUC/AP/ECE、mean、standard deviation、worst-subject、最佳 epoch、训练时长和参数量。必须生成候选相对 E0 的 paired delta 图，不能只展示最好结果。

## 6. 成功门槛

### 最低可接受门槛

- 内层三折 mean F1 相对 E0 提升至少 0.03。
- 内层 mean Recall ≥ 0.750，且任一受试者 Recall 不低于 0.600。
- 固定确认集 F1 ≥ 0.800，Recall ≥ 0.750。
- ECE ≤ 0.150，Brier 不高于当前 0.215。

### 冲刺目标

- 固定确认集 F1 ≥ 0.850。
- Recall ≥ 0.850、ROC-AUC ≥ 0.880。
- ECE ≤ 0.100。

门槛是 promotion gate，不是保证。如果没有候选通过，继续保留当前 release，不上传更差权重。

## 7. 输出产物

- 每次运行的不可变配置 JSON、随机种子和数据 split hash。
- 三折逐样本 predictions JSONL。
- `selection_summary.json`，记录为什么选择或淘汰候选。
- 最终 checkpoint、temperature、threshold、SHA256 和 model card。
- ROC/PR、混淆矩阵、阈值曲线、校准图、受试者 F1 箱线图和消融柱状图。
- 一份中文答辩说明，明确样本量、受试者数量、已知确认集和非临床边界。

## 8. 失败处理与停止条件

- 任一 fold 出现 NaN、空类别或 pose 缺失时，该候选标记失败并保留错误原因，不用零分静默替代。
- 若 E1 不能提高 mean F1，先检查 batch/shuffle/early stopping，而不是增加网络容量。
- 若 E2 提升不足 0.01，删除增强组合中贡献为负的项，不继续叠加增强。
- 若 calibration 降低 ECE 但 F1 下降超过 0.01，保留 temperature、重新在内层验证选择阈值。
- 最多评估 18 个结构/训练候选；超过后停止搜索，避免在小数据上反复试到偶然高分。

## 9. 隐私与比赛表述

训练和评估只读取骨架缓存，不上传原始视频。报告不得把 GMDCSA24 结果描述为真实老人、临床或萤石现场性能。心理健康部分继续只展示趋势与自愿筛查，不生成未经标签验证的“准确率”。
