# 真实预跌倒模型重训练设计

## 目标

把当前的片段级跌倒/ADL 区分实验改造成严格的预跌倒风险训练流程：训练输入不得包含跌倒开始时刻及其后的姿态帧，并按受试者隔离评估。

## 数据与标签

以 GMDCSA24 的 `metadata.csv` 作为视频总时长真值，以统一标注中的 `start_sec` 作为跌倒开始时刻。每个跌倒片段只截取 `[max(0, start_sec - horizon_sec), start_sec - guard_sec]` 的姿态窗口；ADL 从同等长度的窗口中取样。默认 `horizon_sec=3.0`、`guard_sec=0.5`。小于三帧或没有可用窗口的样本必须丢弃并记录原因。

## 模型

第一阶段保留 `PrefallModel` 的标准化逻辑回归接口，输入为 `GaitStabilityAnalyzer` 的尺度不变步态特征和既有运动特征。训练产物必须包含样本数、正负样本数、窗口参数、排除数和按人分组的指标。之后可在同一 CSV 契约上增加 RG-PCNet 时序模型。

## 评估与发布

使用 Leave-One-Subject-Out 评估，报告 Precision、Recall、F1 以及每折指标。默认发布门槛保持 F1 >= 0.90 且 Recall >= 0.88；不满足时保存实验模型，但 `promoted=false`。模型不能标为临床诊断模型。

## 验证

测试必须证明：跌倒窗口不会含有 guard 边界后的帧；ADL 窗口不被标正；缺失时长、无可用窗口和未知媒体路径被明确拒绝；按受试者评估持续可用。
